# 发现列表刷新

移动端在列表顶部下拉重新读取第一页，在底部上拉继续加载下一页；桌面端使用“刷新项目”按钮和原有触底分页。复用 React Native `FlatList` 的原生刷新控件，不增加手势库或业务接口。

介绍、搜索框和排序栏位于列表外，固定在顶部；只有项目标题、计数及卡片参与列表滚动与下拉回弹。横屏等高度不足 500 的窗口隐藏介绍文案，为列表保留空间。搜索和排序不随刷新移动，也不在列表更新时重新创建。

`FeedController.refresh()` 保留当前搜索、排序及已有卡片，成功后用第一页结果替换旧列表，后续继续请求第二页。刷新期间阻止重复刷新和分页；刷新会使之前的分页请求失效，切换搜索或排序又会使旧刷新失效。首次加载、分页和刷新分别呈现骨架、底部加载动画和原生刷新动画，桌面按钮同时显示加载指示器。

刷新失败保留卡片、总数、页码和末页状态，在列表顶部显示错误与重试；不会自动循环请求。原生短列表和空列表也允许下拉。桌面端不模拟触摸回弹，使用可点击、可键盘操作的刷新入口。

实现与验证顺序：

1. 控制器回归先在旧实现失败，覆盖刷新保留内容、第一页去重、末页刷新、失败重试、重复手势以及翻页/搜索的过期响应。
2. 接入共享发现页，验证六种视口的刷新动画、保留内容、搜索排序、重新分页和错误重试，并保留已有触底加载行为。
3. 运行统一检查、prek、Web 构建和原生打包检查，记录实际覆盖范围至 `validation.md` 后阶段提交。

# 分阶段实施与验收

**目标：**交付可运行的公开工程浏览与二维 PCB 查看客户端，并将每个可验证阶段提交到 `gouzil/oshwhub_app`。

**架构：**[design.md](design.md)。React Native 共享 UI，Rust 共享业务；移动端本地桥、桌面 Tauri、开发环境 loopback 服务；Rust 几何与自研 Skia 二维渲染器。

**执行方式：**连续推进用户已授权的工作。研究和独立模块可以并行，集成、验证和提交串行；不等待重复确认。设计变化和验收限制写入文档。

## 全局约束

- 保持 Rust 为业务主体；共享协议不在平台壳中重复实现。
- 仅公开读取；账号和写入行为后续迭代。
- 不复用 easyeda-viewer 渲染器，不复制闭源 smt-gl-engine；Skia 为通用绘制后端。
- 阶段完成后提交；Git 只暂存该阶段明确文件，不使用 `git add -A`。
- 测试与真实在线/设备验证分开记录。任何未通过项必须记录，不能用配置存在证明平台可用。

## 高优先验证条件

1. 418、限流、无网络、空结果：保留可恢复界面并允许重试。
2. 搜索切换/重复分页/返回详情：过期请求不能覆盖当前数据。
3. 历史缺页、删除、重复 ID、损坏或过大载荷：拒绝不完整/危险工程。
4. 320px、平板分屏、横屏和大字体：工具栏可操作，无横向溢出。
5. 密集 PCB、重复打开/关闭、双指手势：避免重复解析和监听泄漏。

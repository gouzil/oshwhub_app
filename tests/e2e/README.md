# 浏览器回归

在仓库根目录运行：

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

本地复用 `http://127.0.0.1:5173`；没有现有服务时自动启动桌面 Vite 开发服务，CI 启动独立服务。无需 Rust 核心或外部 API：测试拦截 `http://127.0.0.1:4318/bridge`，返回自制项目和 PCB 场景，并为正文图片提供本地自制 PNG；CanvasKit WASM 和完整 Noto Sans SC 字体仍由应用实际加载。Chromium 使用 SwiftShader 软件 WebGL。

各尺寸覆盖以下流程（以 Playwright 的实际收集结果为准）：

- 320×720、390×844、768×1024、1024×768、1440×900、844×390。
- 静置与隐藏列表不会自动翻页；应用高度受视口约束，没有页面横向溢出。
- 搜索、排序、分页、详情原样安全正文、正文图片实际解码及宽高比、板子切换、含空料号的 BOM、返回后滚动位置。
- Enter 使用提交事件中的当前原生文本；快速输入后搜索按钮使用同步更新的最新草稿；清除搜索重置结果。
- CanvasKit 实际截图中的铜层、中文和面积；按钮、键盘、滚轮缩放；真实浏览器单指拖动与双指缩放；隐藏图层后的像素与拾取参数。
- 图层控件将默认可见层排在默认隐藏技术层前；切换可见性后控件保持原位。
- StrictMode 挂载/卸载、连续三次 Fast Refresh 后的实际铜层/中文像素，以及强制测试 GC 后的 CanvasKit Picture finalizer；不写入或热改仓库源文件。
- HTTP 418 的可见错误、诊断信息及原页重试。
- 慢响应的骨架动画与减少动态效果；正文图片临近视口才下载、缩略失败回退原图、图片独立重试，以及长海报的自然比例。
- 悬浮底部导航和圆角侧栏的材质、切页、选中态与触控尺寸；短横屏下静态页末尾和详情 BOM 按钮可以滚到导航上方；Chromium 的降低透明度模拟验证实色回退。

图片用例先将正文区域滚入视口，分页用例滚到最后卡片的起点。直接跳到页面末尾可能越过尚未进入视口的图片，不能代替按需图片加载测试。WebKit 补测时，依赖 Chromium CDP 的用例应显式跳过。

监听 `pageerror` 和 `console.error`；仅允许人为注入 418 对应的浏览器资源错误。通过用例保存实际 PCB 截图，失败用例保留页面截图和 trace，输出在已忽略的 `test-results/`。这些离线回归不证明线上 API、原生 GPU、真机手势或所有 Android IME 原生事件时序。

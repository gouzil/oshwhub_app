# 浏览器回归

在仓库根目录运行：

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

本地复用 `http://127.0.0.1:5173`；没有现有服务时自动启动桌面 Vite 开发服务，CI 启动独立服务。无需 Rust 核心或外部 API：测试只拦截 `http://127.0.0.1:4318/bridge`，返回自制项目和 PCB 场景；CanvasKit WASM 和完整 Noto Sans SC 字体仍由应用实际加载。Chromium 使用 SwiftShader 软件 WebGL。

每个尺寸运行三项测试，共 18 项：

- 320×720、390×844、768×1024、1024×768、1440×900、844×390。
- 静置与隐藏列表不会自动翻页；应用高度受视口约束，没有页面横向溢出。
- 搜索、排序、分页、详情原样安全正文、板子切换、BOM、返回后滚动位置。
- CanvasKit 实际截图中的铜层、中文和面积；按钮、键盘、滚轮缩放；真实浏览器单指拖动与双指缩放；隐藏图层后的像素与拾取参数。
- HTTP 418 的可见错误、诊断信息及原页重试。

监听 `pageerror` 和 `console.error`；仅允许人为注入 418 对应的浏览器资源错误。通过用例保存实际 PCB 截图，失败用例保留页面截图和 trace，输出在已忽略的 `test-results/`。这些离线回归不证明线上 API、原生 GPU 或真机手势表现。
